# 用户要的固定步骤

以后换一个地点，也走这八步。第一步地点可以是用户自己写的，例如人在长春，句子里写的是白山。以句子里的地点为准，不以浏览器定位为准。

1. 查这个地点的公开资料。资料不够就缩短场景，不要补考古报告里没有的屋顶、衣料、人名和一天的天气。
2. 用资料约束 GPT Image，出一张场景图。
3. World Labs 只吃这张场景图，做远处的世界和碰撞体。
4. Tripo 另做场景里的人和物件。人按资料允许的服饰和生活状态做。物件一件一个模型。
5. 语言模型按同一份资料写很短的说明，走 human-writing。口语，一两句。不知道就说没有留下。不要冒号、破折号，也不要先否定再翻过来说。第一人称是教学对白，不是古人原话。
6. Tripo 的模型叠在 World Labs 世界上面。中间要有一块贴着远处地形的近景地面，边缘淡出，不能挖出黑缝。
7. 近景模型和人物用 Three.js 阴影贴图，让物件有体积。远处的世界贴图收不到这块阴影。
8. 人在这个地点走完、问完，地图上这个点亮起。人越多，亮的点越多。

左家山一期后段已经有现成资产。新地点在研究、场景图、世界和模型都落盘之前，页面不能假装已经生成。

# 这仓库实际做成的

只有吉林农安左家山一期后段，本机页面 `http://127.0.0.1:4317/#journey`。

资料是吉林省地方志左家山条目和用户实拍展签。没有按用户随口说的城市去全网检索，也没有为白山或别的地点生成世界。定位只用来估到已知遗址的粗距离，不能证明人站在遗址上。

GPT Image 画的是一张没有房屋、没有陶罐、没有人的河岸。World Labs `marble-1.1-plus` 用这张图做成远处溅射世界和碰撞体，实际用过 3080 credits。Tripo 另做了房屋、陶罐、草、枝材、骨器、生活残留和站立的人，叠在一块贴合碰撞体的近景地面上。整张 Tripo 大场景因为质量不够，已经从网页撤下。

人走近房屋后，向导起身，面向来访者走过来。声音是晓晓神经网络人声，不是浏览器电子音。四句预设对白加上当场追问。追问走 DeepSeek，材料仍是那份地方志预设。问「你是谁」，答住在这方屋子里、针在手里、名字没有留下。问罐子，只说到灰褐、弦纹、席纹、之字纹，以及装过水还是粮食并没有写明。鱼骨和蚌壳是整个遗址有的，不能说成这只罐子里的东西。骨针只说明有穿缝，不能指定皮、麻或树皮。

阴影是 Three.js 软阴影贴图，加在近景物件和人物上。河面那层世界贴图没有阴影。

# 理解差在哪

用户以为输入任意地点就会调研并生成开放世界。代码里只有一处做好的左家山一期样本，不能换地点重跑。

用户以为 World Labs 收到的是带着人和物件的完整场景图。实际送给 World Labs 的是空河岸。人和物件是后来叠上去的。

用户以为叠层和衔接还没做。叠层已经是现在的页面结构。剩下的是接缝看起来是否被接受，不是从零发明叠层。

用户以为说明文字还在下一步。四句短对白和当场追问已经在页面上，并按 human-writing 收过口。

用户今天又说到用 shader 做阴影体积。已经选定并装上的是 Three.js 阴影贴图。远处世界贴图仍然没有接收阴影。不要另起一套体积光，除非用户再明确要求。

用户要的地图点亮、聊完点亮、越多人玩越多点亮，这里没有。也没有账户。入口页上的旧石器到新石器地图，也不在这个仓库里。
