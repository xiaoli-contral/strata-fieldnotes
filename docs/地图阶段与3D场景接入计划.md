## 每个新遗址复用的流程

复用技术流程，替换地方证据、图像、世界、物件和对白。左家山资产保留在原路径，新地点使用独立场景 ID 与目录。

1. 整理用户展签和官方、博物馆、发掘资料。逐项登记地点、分期、年代口径、URL、核对日期、证据和未知事项。旧 PDF 和旧地图只作检索线索。
2. 用证据约束场景构图与独立物件参考图。整体构图按用户既定要求先供确认，再进入建模。
3. 用无近景建筑、人物和陶器的环境图生成 World Labs 远景与碰撞体；记录比例、方向与资产状态。
4. 将已确认组件图分别交给 Tripo 建模。逐件检查形状、尺度、贴图和适用分期；人物绑定与动画单独验收。
5. 在同一坐标系装配近景可行走地面、物件和人物，匹配远景地形并处理边缘、阴影、碰撞和成人视角。
6. 为该遗址独立编写短对白与物件说明。未知事项保持未知；追问检索限定到该遗址资料，不能沿用左家山的证据回答其他地区问题。
7. 验证加载、移动、靠近触发、语音、字幕、介绍、返回和失败回退。完成并备份后，才将地图入口标记为可探索。

每个步骤开始前保留上一版；完成后记录变更、检查结果、任务 ID 和费用。不得因刷新页面重复提交生成任务。恢复备份时先保存当时现状，再解包到新目录检查后回退。
