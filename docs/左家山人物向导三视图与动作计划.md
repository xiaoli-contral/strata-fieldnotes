## 史实与设计界限

[吉林省地方志](https://dfz.jl.gov.cn/zsjl/201906/t20190630_5963378.html)提到一期后段骨针、骨锥，但这不能证明图中的人物容貌、年龄、性别、服装剪裁、布料、绑腿、鞋、发式或语言。角色仅是**解释性向导**，不称为“左家山真实居民肖像”。图中的衣服选择便于角色辨识和骨骼测试，面料与款式都要在界面明确标记推测。人物台词将由有来源的考古信息编写，用当代讲解口吻，不冒充古人真实证言。

## 后续开发顺序与准入条件

1. **先验收当前 03 漫游场景**：用户检查陶罐门前距离、生活痕迹贴地、房屋可达与交互；若视觉碰撞仍有问题先修场景并备份。未通过实机验收前不把人物加入网页。
2. **人物输入准备**：从三视图设计定稿派生独立的前、左、后、右四张同尺度全身图。Tripo 当前[多视图说明](https://platform.tripo3d.ai/docs/generation)要求四个槽位按 `[front,left,back,right]` 排列；现有三联图是审稿材料，不能直接作为四张 API 输入。须复核左右方向、A-pose、手指/双腿不粘连、服装与身体不过度融合。
3. **独立 3D 模型**：只提交一项人物多视图任务；下载后检验面部、手、脚、服装层和 GLB 尺寸。模型不得与房屋/土地焊接，不合格不进入下一步。付费前记录拟用版本、费用和新备份。
4. **绑定**：按官方流程先运行免费 `animate_prerigcheck`；若可绑定，再用 `animate_rig` 的现行版本 `v2.5-20260210` 做 `biped` 绑定。官方文档提醒旧 `v2.0-20250506` 已下线，且任何后续网格重构会丢失骨骼数据，故网格编辑必须先于绑定。[绑定前检查](https://docs.tripo3d.ai/animation/pre-rig-check-v2-0-20250506.html)、[绑定接口](https://docs.tripo3d.ai/animation/rig-v2-5-20260210.html)
5. **动画与交互**：分别制作或重定向坐姿待机、起身、转向玩家、站立讲述动作，并测试人物脚底贴地、房屋障碍和相机视线。接近房屋只触发一次，玩家离开后有冷却；用户可静音、跳过、重放讲解。骨骼绑定不自动提供面部口型，张口/圆唇必须另行验证 morph target 或独立面部动画可行性，不能以静态表情图冒充已实现唇形同步。
6. **台词与双语**：先出中文短讲解，逐句链接来源、标出推测；英语版需单独审校。角色为“当代解释性向导”，不能说出其亲历 6700 年前的第一人称回忆。

每个阶段完成后保留独立备份、模型任务 ID、实际 credits、截图和失败记录，验收通过后再进下一阶段。以上为最初计划，后续执行情况如下。
