# 左家山当前版本

2026-10-06。这一包就是现在能打开的左家山一期后段。页面在 `http://127.0.0.1:4317/#journey`。它是一处已经做好的解释性样本。换一个地点之前，先看这份说明，再改对应文件。

## 在另一台机器上打开

需要 Node.js 22 以上。把本机的 `.env.local` 自己带过去，压缩包里没有密钥。里面要有 `WORLDLABS_API_KEY`、`TRIPO_API_KEY`、`DEEPSEEK_API_KEY`。名字见 `.env.example`。

```sh
npm install
npm run build
npm start
```

照片识别还要在 Mac 上执行 `npm run ocr:build`。没有这步时，展签文字可以手填。

已经生成的世界和模型都在 `outputs/`。打开页面会直接用它们。不要去点生成，也不要重新调用 World Labs 或 Tripo。那会再扣费。

## 现在这一版怎么串起来

1. 资料在 `data/catalog.mjs` 和 `data/reconstruction.mjs`。地方志写了方形房址、八个柱洞、灰褐陶、骨针、骨锥。展签和碳十四年代分开保留。定位只是农安城区的参考点。
2. 场景图是 `outputs/left-river-environment-v1.png`。这张图里没有房屋、没有陶罐、没有人。图像不是服务器画的，文件是先做好再放进来的。
3. World Labs 用这张图做出远处世界。页面读的是已经下载的溅射文件和碰撞体，状态在 `outputs/left-river-world.json`。调用代码在 `generation.mjs`，地址是 `api.worldlabs.ai`。
4. Tripo 的模型叠在这个世界上面。近景地面贴着碰撞体，边缘淡出。房屋、陶罐、草、枝材、骨器、生活残留在 `outputs/nearfield/`。站立的人在 `outputs/rigging/standingGuide-rigged-v1.glb`。调用代码也在 `generation.mjs`，地址是 `openapi.tripo3d.ai`。
5. 人走近房屋，向导起身，面向来访者走过来。字幕和声音在 `public/app.js`。四句预设和追问的材料在 `data/guide-speech.mjs`。追问调用 `api.deepseek.com`。声音由 `scripts/edge-speech.mjs` 合成晓晓的人声，文件在 `outputs/speech/`。
6. 阴影在 `public/viewer-entry.js`。近景物件和人物用 Three.js 阴影贴图。远处的河面溅射收不到这块阴影。

服务器入口是 `server.mjs`。它现在只听 `127.0.0.1`。

## 换地方时改这些

新的图像接口接到第 2 步，专门出场景图。认照片、查资料接到第 1 步，可以用以后给的 DeepSeek，也可以用平台里如果能调用的 GPT。这两处现在都还是空的。

换一个遗址时，改资料卡、预设对白和场景图，再决定要不要新生成世界和模型。左家山这一套资产留着，不要覆盖。

口头回答只能用资料里有的句子。屋顶、衣料、姓名、某一天的冷暖，说没有留下。骨针只说明有穿缝。鱼骨和蚌壳是整个遗址有的，不能放进这只罐子。一期房址里不放石龙。石龙是二期的霏细岩龙形佩。

地图点亮、每个人都能打开的公开网页，这一包里还没有。先把这一版在新的地方跑起来，再加。
