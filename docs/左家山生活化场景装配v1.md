# 03 漫游：左家山一期后段生活化装配 v1

日期：2026-10-04。依据用户已批准的[第一张生活化构图](../outputs/左家山一期生活化场景构图-v1.png)、后续[拆件整体摆放图](../outputs/lifestyle/full-scene-layout-v2.png)及[单件决策](左家山生活化拆件决策.md)，在**原 03 漫游位置**更新近景活动区，没有新开模块或重新生成 World Labs 世界。

## 已装配

- World Labs Marble 1.1 Plus 河岸 SPZ 与 collider、逐点贴合的 Tripo 地面、原有 Tripo 房屋/陶罐/草均保留。陶罐从场景前端移到房门活动区附近的世界坐标 `(0.65, -3.75)`；该位置是教学摆放，非出土原位。
- 增加 18 件轻量几何组成的生活痕迹：8 根枝材、2 件骨针/骨锥类型提示、3 枚蚌壳、3 段鱼骨、2 枚陶片。每件在运行时向 Tripo 地面取高，避免平面贴图悬空。它们是**解释性场景层**，并非考古扫描、出土位置图或可证明的同层组合。
- 仍只展示一座房，不假定左家山一期房屋成排或环形分布。屋子和陶罐保留原有近距离点击介绍；房址说明补充全遗址残留不能直接归于这一座一期房屋门前。
- 走向房门的通道保持空出；枝材集中在一侧，残留疏散到另一侧。未加入农田、渔网、石龙、床或会说话的人物。

## Tripo 房屋单件试验

- 使用 `house-semidug-reference-v1.png` 向 Tripo `v3.1-20260211` 图生模型提交了**一项**任务，任务 ID `f6f44156-9694-4c36-bf2d-b678a537a897`，实际消耗 30 credits。模型与预览存为 `outputs/nearfield/houseV2-v1.glb` 和 `houseV2-preview-v1.png`。
- 预览呈现半地穴屋顶与坡道，但 GLB 只有一组 mesh primitive，屋体、坡道及周边土台烘在一起。直接压到现有 Tripo/World Labs 地形会重现硬边或局部埋入；**质检未通过，未接入网页**。继续使用旧屋模型，直到能把土台和建筑拆开、以现有近景地面为基底重新对齐。此结果作为研发试验保留，不因付费完成就强行展示。
- 近景任务状态现报告历史 4 项加本次试验共 150 Tripo credits，明确标记新屋 `deployed:false`。

## 证据与待验收

一期方形八柱洞房址、陶器、骨针、骨锥见[吉林省地方志](https://dfz.jl.gov.cn/zsjl/201906/t20190630_5963378.html)；约三米半地穴房基、斜坡门道来自引述发掘报告的[考古综述](https://szzy.7lue.cn/read/f83472e5f0c45c35354ed3636689030f/9ce858b93f67aa8d12b146fe544b36fc.md)，须对照原图版复核。现网页旧屋的 4.8 米是展示模型全宽，不得称为房基实测宽度。屋顶、枝材和残留位置均为推测。

`npm run build` 与 `npm test` 已通过（11 项）。此环境未完成浏览器实机画面验收，仍需用户检查陶罐是否过近、枝材/残留是否穿地、屋门是否被挡、第一人称行走和点击是否正常；不能仅凭自动测试宣称画面完全合格。

## 2026-10-04 可见性修订 v2（待用户验收）

用户刷新后截图表明 v1 的枝材、骨器和残留近乎不可见，先前“生活化装回场景”的描述不符合实际视觉效果。修订前已封存 `backups/2026-10-04-pre-visible-lifestyle-fix-v1.tar.gz`。

v2 将房前左侧枝材改为约 1.8 米宽、有高度层次的堆放，并增加低矮作业木墩和三枚卵石；陶罐、房屋、World Labs 河岸世界及 Tripo 地面不换版。全遗址鱼骨、蚌壳和陶片线索仍在另一侧，但不据此断言它们与这座一期房屋共时。新增内容共 25 个 Three.js 几何件，都是**可见性与空间排布试验**，不是新增 Tripo 文物模型，也没有证明木墩在遗址中存在。网页 03 画面左上角显示“近景试排 v2”，用于核对是否加载新版。

已用真实 World Labs collider 与 Tripo 地面资产检查所有 25 件的地面覆盖，`npm run build` 和 11 项自动测试通过；**尚未取得浏览器画面和行走体验的人工验收**。若用户截图仍显示旧构图，需要继续检查渲染遮挡或装配/缓存，不得将本版标记为通过。人物参考图单独保存，人物模型、骨骼绑定、动作和台词均未在网页启用。

下一阶段仅在本版备份后启动：制作**同一虚构向导**的人物正面、侧面、背面模型参考及面部表情参考；先质检人物一致性，再决定是否提交 Tripo 人物模型与骨骼绑定。人物容貌、性别、衣着、台词均不得伪称为具体的左家山古人资料。人物靠近时起身、转向玩家和说话动作为后续独立阶段，不在本版网页中实现。
