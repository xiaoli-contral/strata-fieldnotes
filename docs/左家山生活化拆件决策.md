## 证据约束

[吉林省地方志左家山条目](https://dfz.jl.gov.cn/zsjl/201906/t20190630_5963378.html)支持一期后段一座方形、八柱洞房址，以及房内沙质灰褐陶、骨针、骨锥等。鱼骨、蚌壳和兽骨是**全遗址**发现，不能被标成这座一期房屋门前的精确出土位置。屋顶、衣料、枝材堆、活动路线均属解释性补全。[考古综述](https://szzy.7lue.cn/read/f83472e5f0c45c35354ed3636689030f/9ce858b93f67aa8d12b146fe544b36fc.md)提及约 3 米方形半地穴房、坡道和偏侧灶；原始发掘图版仍需复核。二期石龙、三期骨鱼镖、明确农田和多房聚落不进入这一期场景。

## 图像提示词摘要

- 陶罐：单件灰褐沙质筒形罐，厚沿、略收底、克制的之字纹，透明背景；v1 过长，v2 将高宽比收敛至约 1.2–1.35。
- 骨器：并列但不重叠的骨针和骨锥，象牙白，三分之四角度，透明背景，非原物复刻。
- 枝材：低矮疏松的落枝堆，无锯痕、绳索和现代工具，透明背景。
- 残留：少量淡水蚌壳、鱼骨和灰褐陶片，俯视、分散、非祭祀或完整餐食，透明背景。
- 房屋：单座约 3 米方形浅半地穴房、坡道入口、解释性木柱和草/土屋顶，三分之四角度，透明背景；不能将屋顶外形写成发掘事实。

所有图片通过内置 imagegen 生成，不是 CLI/API 绘图；包含透明通道。下一阶段开始前先生成本阶段备份并校验；任何付费 Tripo 任务只能由明确的单件候选启动，不把整张场景图投入单体模型接口。
