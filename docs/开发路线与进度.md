# 层迹 · 长期开发路线与进度

更新：2026-10-05。当前对象只限吉林农安左家山一期后段的解释性试验，不把中国各地区的新石器时代当成同一条统一时间线。

## 证据规则

1. 用户照片和位置分别处理。文字命中只产生候选；位置仅用于区域参考距离，不能证明用户站在遗址上，也不能由附近遗址推出当前位置曾有同一文化。
2. 每个场景元素登记“地点—文化层/分期—年代口径—来源—可信度—视觉补全”。左家山一期筒形陶罐可进入一期场景；二期石龙不可挪到一期。未给出出土微坐标时，只能在场景中示意摆放。
3. 对比国外器物前，先统一年代口径：未校正的碳十四 BP、校正后的 cal BP 和公元前纪年分列，不直接做一比一换算。比较同时间窗的技术/用途，不用“先进/落后”排名。
4. 建筑、衣着、植物、声音和人物台词若没有地方性材料，只作为解释性想象，并在用户触碰时可查看证据与不确定性。人物第一人称台词不冒充史前当事人的真实记忆。
5. 公共网页、博物馆和政府资料保留原始 URL、访问日期、可用许可及摘录范围；图像生成不替代考古报告。重要事实优先取发掘报告、机构资料和原始展签。

主要来源：[吉林省地方志左家山条目](https://dfz.jl.gov.cn/zsjl/201906/t20190630_5963378.html)，用户实拍的左家山展签；技术边界：[World Labs 世界资产说明](https://docs.worldlabs.ai/api)和[SPZ 比例/坐标说明](https://docs.worldlabs.ai/api/rendering-spz)。

## 分阶段交付

| 阶段 | 可验收交付 | 仍未解决的边界 |
| --- | --- | --- |
| 0 · 保护现状 | 变更前备份、校验值和回退说明 | 不将密钥打包；不自动删除用户原始产物 |
| 1 · 入口与一期漫游（已封存） | 匹配资料及确认区域后进入独立探索页；撤下 Tripo 整景单体模型；Plus splat 与真实 collider 同源对齐；成年眼高、地面/障碍物限制；一期陶罐置于地面，可近距离触发提示、轻提示音和来源解释 | 尚未完成浏览器实机视觉验收；陶罐位置是教学示意；撞击音不是史前声音复原 |
| 2 · 场景拆件（近景实验版） | 四张独立 GPT Image 组件图、四项 Tripo 图生 3D 任务；质检后仅装配房屋与两色草模型，土面改为贴地网格；网页可一键开启/关闭近景层 | Tripo 土地模型因厚板状外形被淘汰；房屋屋顶/墙材/植被为推测；仍需人工漫游、检查拼缝/穿插/帧率 |
| 3 · 身体感与声音 | 脚步、地表差异、风/草/水声分轨；轻量植被动画；无障碍替代；移动端行走控件 | 水、草、麦田是否适用左家山须单独核验；无证据的“古人喊声”不能作为真实声音 |
| 4 · 人物与叙事 | 骨骼绑定、动作、接近触发、第一人称讲述；每句台词带来源/推测标记 | 不能由器物推断个人真实年龄、服饰、心理与每日轨迹 |
| 5 · 扩区与双语 | 新遗址独立分期、地理核验、英语内容审校、跨区域同期器物对照 | 需要机构资料授权、地理与年代专家审阅 |

每一阶段进入下一阶段前执行：备份 → 测试/截图与人工漫游 → 记录缺陷及证据争议 → 用户确认体验方向 → 再开发。任何新的付费生成任务先列明预计额度和是否可复用既有任务；不会因为重新载入页面重复提交。
